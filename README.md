# 🇲🇦 Moroccan E-Commerce Intelligence

An end-to-end data analytics project analyzing sales, profitability, 
product performance, geographic trends, and seasonality in a Moroccan 
e-commerce dataset.

The project combines **SQL Server** for data preparation and analysis 
with **Power BI** for interactive business intelligence and visualization.

---

## 📊 Project Overview

The objective of this project is to transform raw Moroccan e-commerce 
transaction data into actionable business insights.

The analysis focuses on:

- Sales and revenue performance
- Profitability and profit margins
- Product category and sub-category performance
- Geographic performance by city
- Monthly sales trends and seasonality
- Identification of loss-making markets
- Business recommendations based on analytical findings

---

## 🛠️ Tools & Technologies

| Tool | Purpose |
|---|---|
| **SQL Server** | Data cleaning, transformation and analysis |
| **Power BI** | Data modeling, DAX measures and dashboards |
| **Power Query** | Data preparation and transformation |
| **Excel** | Initial data inspection and source data |
